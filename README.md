# 👨🏻‍💻 Customer Behavior Data Analyst Portfolio Project

## 📌 Project Overview

This project simulates a **corporate-grade, end-to-end data analytics workflow**, demonstrating how raw customer shopping data can be transformed into meaningful business insights. The project mirrors the real responsibilities of a Data Analyst by covering the complete analytics lifecycle—from data preparation and analysis to visualization and business reporting.

Using **Python, MySQL, and Power BI**, this project showcases practical skills in data cleaning, SQL analysis, dashboard development, and business intelligence.

---

## 🎯 Project Objectives

- Clean and prepare raw customer shopping data for analysis.
- Analyze customer purchasing behavior using SQL.
- Segment customers based on purchase history.
- Discover purchasing trends and business insights.
- Develop an interactive Power BI dashboard.
- Present findings through a professional report and presentation.
